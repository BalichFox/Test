1. Что такое Active Directory и зачем она нужна?
Active Directory (AD) — это служба каталогов от Microsoft, которая организует централизованное управление пользователями, компьютерами, 
группами и другими ресурсами в компьютерной сети. 
Проще говоря, это «центр управления» всей ИТ-инфраструктурой компании, где администратор задаёт правила и контролирует доступ. 
2. Чем отличается домен от леса? А OU от группы? 
Домен — это логическая группа объектов: пользователей, компьютеров, принтеров и других ресурсов, у которых общая база данных, 
единая система аутентификации и централизованные правила управления. 
Проще говоря: внутри домена все объекты «говорят на одном языке» — у них одинаковые схемы атрибутов и правила безопасности. 
Лес — это уже контейнер верхнего уровня. Он объединяет один или несколько доменов, которые разделяют общую схему каталога 
(описывают, какие объекты и какими атрибутами могут обладать), общую конфигурацию (как устроена топология, как идёт репликация) и работают в одном пространстве доверия. 
Лес задаёт внешнюю границу безопасности: 
объекты из разных лесов по умолчанию не взаимодействуют, если администратор специально не настроит между ними отношения доверия. 
Организационное подразделение (OU) — это контейнер внутри домена. Его создают, чтобы логически сгруппировать объекты (например, выделить отдельный OU для отдела кадров, серверов или рабочих станций). 
С помощью OU удобно строить иерархию, делегировать административные права (например, дать менеджеру право управлять учётными записями в своём OU, но не во всём домене) и применять к нему групповые политики. 
OU существуют только внутри домена и могут быть вложенными. 
Группа в Active Directory — это тоже контейнер, но его роль другая. Группа собирает в себя другие объекты:
учётные записи пользователей, компьютеров или даже другие группы.
Группы используют, чтобы удобно управлять правами доступа: вместо того чтобы назначать разрешения каждому объекту отдельно, вы добавляете нужные объекты в группу и даёте группе права на ресурс. 
Есть два основных типа: группы безопасности (для назначения прав к сетевым ресурсам) и группы распространения (в основном для рассылки электронных писем, например, в Exchange). Важно:
к самим группам нельзя применять групповые политики.
3.Почему DNS критически важен для AD?
DNS (Domain Name System) критически важен для Active Directory (AD) потому, что служит основным механизмом,
который позволяет клиентам (компьютерам и серверам) находить контроллеры домена и другие ключевые ресурсы в сети. 
Без корректной работы DNS AD просто не сможет функционировать.
4. Что такое DSRM-пароль и зачем он нужен?
DSRM-пароль (Directory Services Restore Mode password) — это пароль, 
который используется для входа в специальный режим загрузки контроллера домена в Windows Server, 
предназначенный для аварийного восстановления и обслуживания Active Directory. 
5. Какие команды PowerShell вы использовали сегодня?
1. Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools
2. Install-ADDSForest `
    -DomainName "company.local" `
    -DomainNetbiosName "COMPANY" `
    -InstallDns:$true `
    -SafeModeAdministratorPassword (ConvertTo-SecureString "P@ssw0rd123!" -AsPlainText -Force) `
    -Force
3. # Проверка домена
   Get-ADDomain

   # Проверка контроллера домена
   Get-ADDomainController

   # Проверка леса
   Get-ADForest

   # Проверка служб AD
   Get-Service NTDS, DNS, Netlogon, KDC
 4. dsa.msc — Active Directory Users and Computers (ADUC).
    dssite.msc — AD Sites and Services.
    domain.msc — AD Domains and Trusts.
    dnsmgmt.msc — DNS Manager.
5. # Создаём корневое OU
New-ADOrganizationalUnit -Name "Company" -Path "DC=company,DC=local"

# Создаём вложенные OU
New-ADOrganizationalUnit -Name "Users"     -Path "OU=Company,DC=company,DC=local"
New-ADOrganizationalUnit -Name "Computers" -Path "OU=Company,DC=company,DC=local"
New-ADOrganizationalUnit -Name "Servers"   -Path "OU=Company,DC=company,DC=local"
New-ADOrganizationalUnit -Name "Groups"    -Path "OU=Company,DC=company,DC=local"
