📚 OSI — 7 уровней

7. ApplicationСервисы для приложений (HTTP, DNS, SMTP)
6. PresentationКодировка, сжатие, шифрование (TLS, JPEG)
5. SessionУправление сессией (RPC, NetBIOS)
4. TransportДоставка сегментов, порты (TCP, UDP)
3. NetworkМаршрутизация, IP-адреса (IP, ICMP)
2. Data LinkКадры, MAC-адреса (Ethernet, Wi-Fi)
1. PhysicalБиты, кабели, сигналы

⚖️ TCP vs UDP

TCPСоединение, доставка, порядок, повтор
UDPБез соединения, без гарантий, низкая задержка
TCP: HTTP, HTTPS, SSH, SMTPГде важна целостность
UDP: DNS, DHCP, VoIP, видеоГде важна скорость
TCP handshakeSYN → SYN-ACK → ACK (3 шага)
TCP teardownFIN → ACK → FIN → ACK (4 шага)

📨 HTTP — методы

GETПолучить ресурс (параметры в URL)
POSTОтправить данные (тело запроса)

PATCHЧастичное обновление
DELETEУдалить ресурс
HEADТолько заголовки, без тела

🔢 HTTP — статус-коды

2xxУспех (200 OK, 201 Created, 204 No Content)
3xxРедирект (301 Moved, 302 Found)
4xxОшибка клиента (400, 401, 403, 404)
5xxОшибка сервера (500, 502, 503)
401 = нужна аутентификация · 403 = доступ запрещён · 404 = не найдено

🩺 Диагностика — база

ping <host>Доступность (ICMP)
tracert / tracerouteПуть до хоста (Windows / Linux)
ipconfig /all (Win)IP, DNS, DHCP
ip a (Linux)Адреса интерфейсов
nslookup <домен>DNS-запрос (Win/Linux)
dig <домен>DNS-запрос (Linux, подробно)
netstat -ano (Win)Соединения + PID
ss -tulpn (Linux)Слушающие порты

🩺 Диагностика — продвинуто

nmap -sV <host>Сканирование + версии сервисов
nmap -p- <host>Все TCP-порты
curl -I <url>HTTP-заголовки ответа
curl -v <url>Подробный HTTP-обмен
tcpdump -i any port 443Захват трафика
mtr <host>Трасса + потери пакетов
openssl s_client -connect host:443Проверка TLS/сертификата
